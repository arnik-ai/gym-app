# Gym Telegram Mini App (demo)

Single-page Mini App (plain HTML, no build). Opens inside Telegram from a bot's menu button.
Digital membership card with days left and an entry QR (sample, not scannable); class booking on a Shamsi calendar
with women's and men's hours, free seats and a waitlist; membership renewal with plans, locker, personal coach and diet plan,
a start day picked on the calendar and 4-part installments; workout program with done ticks and a rest timer; instant Q&A.
Sample data only. PREVIEW = true: bookings and payments send nothing yet.
